# 🌍 Language Translation Tool

A simple and user-friendly language translation tool built using Python, Gradio, and MyMemory Translator.

## 🚀 Live Demo

👉 [Click here to try the Language Translation Tool](
https://5ebed1221963e8f11c.gradio.live/)
## ✨ Features

- Translate text from one language to another
- Select the source language
- Select the target language
- Supports multiple languages
- Simple and easy-to-use interface
- Real-time translation
- Built with Gradio

## 🛠️ Technologies Used

- Python
- Google Colab
- Gradio
- Deep Translator
- MyMemory Translator
